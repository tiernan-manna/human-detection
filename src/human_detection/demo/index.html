This page is a client of the sidecar, not its own detector. It synthesises load by sending frames into /detect at the configured rate. Use source = still images to cycle the bundled sample_images/ folder for a quick visual sanity check, or source = recording to replay a captured session — original telemetry and low-light flags are forwarded so the altitude gate, hover boost and motion gate behave exactly as they did in flight. Frames sent from this page are flagged isDemo and never appear in the live monitor or recordings; running it alongside manna-dash just stacks demand on the same sidecar process.
