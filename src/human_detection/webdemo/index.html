This page runs the entire detection pipeline in your browser: ONNX WALDO v3 via onnxruntime-web (WebNN → WebGPU → WASM), plus a JS port of the sidecar's post-processing (crosshair inpaint, ByteTrack, hover/altitude/motion gates, predicted-box persistence). The local sidecar is only used to serve recordings/model files — and as the reference pipeline for the compare overlay and benchmark. WebNN needs Chrome started with --enable-features=WebMachineLearningNeuralNetwork.
